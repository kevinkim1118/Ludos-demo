Foundations — Crimson noir

Dark-first. Wine-graphite base, crimson accent, warm↔cool diverging sentiment. The canonical token reference the hi-fi screens build on.

v1 · dark theme primary · light theme ported · type: Familjen Grotesk + Newsreader

The crimson restraint rule. Crimson means sentiment or primary action — nothing else. Alignment, status-current, and structural accents stay neutral. Proven on the dense finished/cold-start states: when crimson did extra duty (alignment chips, callout frames) the page got loud and "aligned" risked reading as a rating. Reserve it, and the red stays the loudest, most meaningful thing on screen.

Color · neutrals & elevation

One wine-graphite ramp does the structural work — warm, but tinted distinctly off a neutral graphite so the dark reads as its own world. Surfaces step up by lightness (page → card → popover); the eye reads elevation, not borders.

Three meanings, three axes: action = crimson (hue, reserved) · sentiment = warm↔cool (hue, diverging) · trust = brightness (neutral). No axis does double duty.

Color · semantic

Kept small — warm/cool sentiment already carries “good/bad.” In a crimson house, destructive must not lean on red alone (it would echo the brand); danger is a muted brick paired with iconography + confirmation. Success is low-chroma sage, also used for the “agreed” check on relate chips.
