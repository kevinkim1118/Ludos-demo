Annotations — mobile reflows of the Library page
1The paralysis-breaker still leads. "What to play next" sits above the fold — one confident pick with its reasoning, the same JTBD-02 answer as desktop, stacked vertically.
2Time context collapses to a compact chip in the hero header; tapping opens a sheet of time options.
3Head-to-head becomes a single tappable bar under the pick (the desktop side panel doesn't fit). Tapping opens the full-screen "compare two" flow — now fully built (see headtohead-wireframe-mobile.html): an intent question first ("what are you in the mood for?"), then quick A/B taps. Play-only. When the Want list has under 2 games, this bar is gated (disabled "add games" hint — reference below).
4Status segments become a horizontal segment control — Want / Playing / Finished / All with counts. The primary organization, thumb-swipeable.
5Custom lists move into a secondary "Lists" link in the sub-toolbar (the sidebar's lists group has nowhere to live on mobile). Opens a sheet of the user's lists + "New list."
6Grid drops to 2-up cover cards; footer data still reweights by status (match + time for Want, progress for Playing, sentiment pill for Finished).
7Bottom tab bar — Library is a top-level destination, so it gets persistent app-shell navigation (Discover / Library / Friends / Search) rather than the detail page's back-arrow header.
