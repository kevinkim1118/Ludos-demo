2Supporting detail sits below the headline. The headlined action shows its evidence — cover thumb + sentiment pill + review snippet (or a list chip). Nothing unrelated to the headline appears on the card.
3Investigate path. Tapping a headline or its detail opens that game's detail page to read the full take — the JTBD-03 hook, intact on mobile.
4Filters are a horizontal chip row under the header (the desktop sidebar's "Show" group). All activity / Finishes & reviews / Ratings / Playing.
5Recency ordering, grouped by time (Today / This week) — same as desktop. Taste-matched friends carry a "Same taste" badge but don't jump the order.
6Connect-Steam growth lever appears inline in the stream (no sidebar to host it). The friends list moves behind the header's people icon.
7Bottom tab bar — Friends is a top-level destination, consistent with the Library page's app shell.
