Wireframe — Discover / Home (logged-in) — Desktop (1200px)
The app's home surface — the trusted-discovery engine. Where the Library decides among games you already track, Discover finds new games to add to your Want list. The page is ordered top-to-bottom by the locked trust ladder (friends → taste-matched → global), so the surface itself descends from personal to anonymous. Discover is at-a-glance: the rail tells you why a group is here; per-game detail (which friend, match strength, review breakdown) lives one tap away on the game detail page. Grayscale lo-fi; reuses the locked nav, hero, game-card, and trust-ladder grammar.
Annotations — how the home does its job
1Discover ≠ Library. Library breaks paralysis among games you own; Discover is top-of-funnel — surfacing new games and converting them to the Want list. The two are a matched pair, not duplicates.
2One confident spotlight leads — the locked "confident pick leads" pattern. It carries a compressed why — the top two trust rungs (taste + friends) in plain language. Primary action is + Add to want list. The full breakdown (distribution, per-friend takes) is deliberately left for the detail page.
3The page IS the trust ladder. Rails descend friends → taste-matched → similar/tag → global. The rail title + tier badge carry the "why this group" at a glance — so individual cards don't need to repeat it.
4Cards are at-a-glance only — cover, name, platform. No per-card signals (friend names, match labels, review breakdowns); those would clutter a scan surface and belong on the detail page. Tap a card to go there.
5The one card action is a quick "+" — adding to the Want list is the core discovery conversion, so it stays on the card. Every other "tell me more / decide" action happens on the detail page.
6Tag-based discovery survives cold-start — "Because you finished Elden Ring" is content-driven, so it works before the social graph fills.
7Cold-start lever (shown below). Empty friends graph → the friends rail collapses to "Connect Steam to import friends," consistent with the detail page and feed. The growth engine, reframed from a gap.
