Wireframe — Friends activity feed — Desktop (1200px)
Friend-centric digest model: each card is ONE friend's recent activity, headlined by their main action ("Alex just finished Elden Ring," "Maya left a review for Hades," "Jordan added Citizen Sleeper to Cozy night-ins"). Serves JTBD 05 (social awareness) + JTBD 03 (see a friend's full take) — the user spots what a friend did, taps in to read the take (which influences their own interest), or takes it off-platform to start a conversation. Convergence signal ("3 friends finished this") is intentionally NOT the feed's job — that lives on the game detail page's verdict. Grayscale lo-fi; reuses avatars, sentiment pills, and status grammar from the existing set.
Annotations — friend-centric digest, kept clean
1Each card is headlined by the friend's main action, in plain language — the event leads, not just the name. "Alex just finished Elden Ring," "Maya left a review for Hades," "Jordan added Citizen Sleeper to a list." The card carries only what relates to that one action, keeping the feed focused. (Noise control now leans on recency + filters; how to represent a friend with several recent actions — likely separate compact cards — is an open thread.)
2Supporting detail sits below the headline. The headlined action shows its evidence — cover thumb, sentiment pill, and review snippet (or a list chip for a list action). Nothing unrelated to the headline appears on the card.
3The investigate path. The headline + snippet are the JTBD-03 hook: a friend's take, one click from their activity, influencing whether the user wants to play it. The whole row links to that game's detail page.
4"Same taste as you" badge surfaces taste-matched friends (the highest-intent signal) without reordering the feed — recency still drives order; the badge just adds weight to the read.
5Recency ordering, grouped by time (Today / This week). This is an awareness feed — "what have my friends been up to lately" — not an algorithmic ranking. A sort control is available but recency is the default.
6Filters are the user's clean-up lever. "Finishes & reviews" vs. all activity lets the skeptical user strip the feed to pure high-signal. Per-friend filtering lives in the friends list below.
7No in-app conversation (by decision). The feed's job is to create the opening — surface that Sam beat a game — and the user reaches out via Discord/text. So there's no reply/comment UI; names link to a profile, activity links to the game.
8Growth lever persists. The friends list ends in "Connect Steam to import friends" — the same cold-start CTA as the game detail page, keeping the trust-ladder/growth story consistent. (A fully-empty cold-start state is a separate variant, not yet drawn.)
