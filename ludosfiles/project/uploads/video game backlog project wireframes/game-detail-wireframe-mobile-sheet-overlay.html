Annotations — the overlay treatment (reference / truer-to-life)
1This is the alternate depiction of the bottom sheet. Instead of drawing the sheet as a separate panel beneath the phone (as the primary deciding wireframe does for static legibility), this shows the real interaction: the sheet slides up over the page, which dims behind a scrim. This is the treatment to realize in hi-fi.
2The page behind is dimmed but still visible — context is preserved, the user knows they can tap the scrim to dismiss. The sheet is the same "Your status" widget: Add to want list / Mark as playing / Mark as finished + "+ Add to a list," with the current status pre-selected.
3Reachability: the sheet anchors to the bottom, thumb-zone first, mirroring where the "Add to List" bar that opened it lives. The slide-up animation and the tap-to-dismiss scrim are hi-fi prototype concerns this static frame only approximates.
