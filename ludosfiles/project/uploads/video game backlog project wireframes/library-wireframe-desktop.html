Wireframe — Library / Backlog management — Desktop (1200px)
Addresses JTBD 02 (backlog paralysis). The page leads with a confident "play this next" recommendation — with a head-to-head "compare two" refine path — then drops into a status-segmented backlog browser (Want / Playing / Finished primary, custom lists secondary). Grayscale lo-fi; reuses the locked game-card, status taxonomy, and sentiment-pill grammar from the game detail wireframes.
Annotations — how the page answers "backlog paralysis"
1The paralysis-breaker leads the page. Per JTBD 02, a daunting library shouldn't open onto a wall of covers — it opens onto ONE confident, specific recommendation. The hero is bordered like the game detail page's hero modules to signal "this is the answer, start here."
2Time context shapes the pick. "How much time have you got?" filters the recommendation toward something finishable in the session — directly answering the research quote about sorting by time but still not being able to choose.
3The pick carries its reasoning — taste match, fits-your-time, and friend signal — the same three trust signals the verdict module uses, compressed. "Start playing" flips status to Playing; "Show another" re-rolls without leaving the page.
4Head-to-head is the refine path — now fully built (see headtohead-wireframe-*). When the single pick doesn't land, this opens the compare flow: first an intent question ("what are you in the mood for?"), then quick A/B taps converge on one game. Play-only — the rating-precision angle was cut. When the Want list has fewer than 2 games, this entry is gated (disabled with an "Add 2+ games" hint — see the reference below the page).
5Status segments are the primary organization — Want / Playing / Finished as the sidebar's main nav with live counts, mirroring the locked want→playing→finished tracking model.
6Custom lists are secondary — listed below the status nav, not competing with it. "+ New list" lives here. (Resolves the detail page's "Add to a list" as a real destination.)
7Cards adapt to the active segment. Want cards show decision data (taste match + time-to-beat); Playing cards show progress; Finished cards show your sentiment rating. Same card, reweighted by status — the detail page's emphasis-shift principle, applied to the grid.
8Sort / filter / view controls. Default sort is Best match (taste-first, not date) so the backlog stays decision-oriented, not just an archive.
