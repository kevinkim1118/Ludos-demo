Launch-day reality for a new user: friends-only platform with no connections yet, no taste-matched reviews for this title yet, only seeded editorial/critic data available. Same page, same modules as the populated deciding state — this shows how each one behaves when the personal signal is empty.
Annotations — what changes when the page is empty
1Identity is unaffected — title, developer, platforms, and tags are always available. Same hero as the populated state.
2The key cold-start move. The trust ladder inverts: the tiers you trust most (friends, then your type) are empty, and the only populated one is the tier you trust least (global, seeded from editorial data). Rather than apologize, the empty Friends rung becomes the strongest CTA on the page — "connect Steam" — turning the cold-start gap into the growth lever that fills it.
3Tracking is fully functional — you can want / play / finish a game on day one regardless of social data. Unchanged from the populated state.
4Purchase confidence carries disproportionate weight at cold start — time-to-beat is utility data, not social, so it's one of the few modules with real signal. (Cost-per-hour line removed per latest decision.)
5Friend signal is empty, but it does not repeat the Connect-Steam CTA — the verdict's Friends rung (2) owns that single primary action. This module shows a lighter "will appear here" state to avoid a competing double-CTA.
6Reviews default tab adapts to available data. Friends and People-like-you are empty (count shown as 0), so the page opens on the only tab with content — seeded editorial reviews, badged "Editorial," never disguised as peer reviews. Recognition over recall: don't open on an empty tab.
7Discovery survives cold start because it's content/tag-based, not social. Relabeled "Similar games" (driven by tags) rather than "Played by Completionists," which would need population to be honest.
8Contribution stays minimal — this is the deciding state, so the user hasn't played yet and can't review. Note: in cold start this module is where seeding begins, so its copy nods to "be among the first," but it does not rise until the finished state.
