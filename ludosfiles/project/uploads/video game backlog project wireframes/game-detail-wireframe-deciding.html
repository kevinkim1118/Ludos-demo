Wireframe — Game detail page — Deciding state — Desktop (1200px)
Annotations
1 Identity header lives in the hero. Key art as full-width background — title, developer, platforms, and motivational tags overlay at bottom-left. Tags feed the taste-match system.
2 Taste verdict is the page's hero module. Three trust tiers stacked in explicit order — friends (strongest signal), taste-matched, global (weakest). Order encodes the trust ladder visually.
3 Tracking actions are sidebar-sticky. Primary CTA ("Add to want list") always visible while scrolling — users can act at any point without returning to the top of the page.
4 Purchase confidence sits below tracking. Price, time-to-beat, cost-per-hour, and store links are always grouped together — never scattered across the page.
5 Friend signal extends the verdict with concrete activity data. Friends-only in v1. Shows ownership, play status, and inline ratings — not a separate review card.
6 Reviews default to Friends tab. Every reviewer carries a gamer type badge — the trust signal is visible without reading the text. Filter order: Friends → People like you → All.
7 Discovery continuation prevents the page from dead-ending. Labeled by type ("Played by Completionists") to reinforce the taste-match system rather than generic recommendations.
8 Your contribution is minimal in the deciding state — dashed border signals deprioritized. This module rises to the top of the page in the finished state.
